# Bundled editorial sample

`onboarding-editorial.png` is an original, AI-generated sample photograph used
only by the permission-free introduction and in-app film examples. It contains
no brands, text, watermark, or user data.

Generation used the built-in image generation tool with the
`photorealistic-natural` use case: two adult friends walking beside a quiet
coastal road in soft late-afternoon light; neutral digital color; portrait 4:5;
realistic skin and fabric texture; broad highlight and shadow range; no baked
film grade, grain, light leak, border, logo, brand, or text. The neutral source
is intentionally processed by Tumble's real shared film renderer at runtime.

# Home sample photographs

`Assets.xcassets/sample-*.imageset` hold five photographs used on Home: the
four film-look cards and the postcard example. They are original,
AI-generated images from `mockups-appstore-v7/photo-library` (prompts in that
folder's `PROMPTS.md`): fictional adults, no text, logos, watermarks, or
celebrity likenesses. Each is a 900 px JPEG re-encode of the source PNG.

| Asset | Source | Used for |
|---|---|---|
| `sample-coastal-drive` | `05-coastal-drive.png` | Faded Instant card |
| `sample-convenience-store` | `01-convenience-store.png` | Disposable card |
| `sample-sidewalk-cafe` | `08-sidewalk-cafe.png` | Silver card |
| `sample-beach-run` | `09-beach-run.png` | Golden Hour card |
| `sample-rainy-crosswalk` | `06-rainy-crosswalk.png` | Postcard example |

The Home before/after hero uses `onboarding-editorial.png` (above), because a
comparison needs a neutral source without a baked-in film character.
