# Bundled editorial sample

`onboarding-editorial.png` is an original, AI-generated sample photograph used
only by the permission-free introduction and in-app film examples. It contains
no brands, text, watermark, or user data.

Generation used the built-in image generation tool with the
`photorealistic-natural` use case: two adult friends walking beside a quiet
coastal road in soft late-afternoon light; neutral digital color; portrait 4:5;
realistic skin and fabric texture; broad highlight and shadow range; no baked
film grade, grain, light leak, border, logo, brand, or text. The neutral source
is intentionally processed by Tumble's real shared film renderer at runtime.
